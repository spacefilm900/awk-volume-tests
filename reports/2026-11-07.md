## Reversal and definitions

`prepare.py` uses Python (not AWK) to reverse the line order, and reverse the whitespace-separated words within every line, joining each nonempty line with single ASCII spaces. Blank lines remain blank. An independent assertion verifies that the whole whitespace-word sequence is exactly the original sequence reversed.

Character total is `sum(length($0)+1)`: bytes in C locale, Unicode characters in a multibyte-aware UTF-8 implementation. Both inputs end in LF. Total words = sum NF (whitespace words, preserving punctuation). Frequency words are a separate definition: maximal ASCII letters/apostrophes, lowercased, with leading/trailing ASCII apostrophes stripped; empty tokens discarded. Curly apostrophes and non-ASCII letters are separators. Thus contractions with curly apostrophes split. Ties are alphabetical. These explicit choices keep results reproducible across locales and implementations.

The sorted top/bottom ten lists are maintained using bounded insertion (O(10 × unique words)); there is no implementation-specific sorting facility.

### Independent validation and a GNU wc trap

Python counts/frequencies were computed independently, using `collections.Counter` and sorted keys. Every output is diffed byte-for-byte with the expected text. `validation.txt` records checks of the reverse sequence, frequency equality, line equality, and `wc -lwc`.

Use `LC_ALL=C POSIXLY_CORRECT=1 wc -lwc ...`. These word, byte and line counts match Python and every C-locale AWK exactly. **Default GNU wc -w under LC_ALL=C reports 963,462, two too many for the AWK definition**: GNU wc treats byte 0xA0 specially as whitespace without POSIXLY_CORRECT, even when it is a continuation byte in UTF-8 à. The two affected lines are `Armed at point exactly, cap-à-pie,` and `_Qui vous là?_`. Minimal example: `printf "a\303\240b\n" | LC_ALL=C wc -w` prints 2; adding `POSIXLY_CORRECT=1` prints 1. This is a counting-definition/utility issue, not a pyawk or hawk bug.

## AWK program

```awk
# Shakespeare volume test: portable POSIX AWK, no extensions.
# Run with LC_ALL=C: length($0)+1 counts bytes including each line's LF.
# In a multibyte-aware UTF-8 interpreter it counts Unicode characters instead.
# The inputs always end in LF. Whitespace words = sum NF (like wc -w in C).
# Frequency words: maximal ASCII-letter/apostrophe sequences, lowercased;
# strip leading/trailing ASCII apostrophes, discard empty results.
# Curly apostrophes and non-ASCII letters are separators, deliberately.
# Ties: ASCII alphabetical. Keep sorted bounded lists by insertion, not a
# quadratic sort of the entire vocabulary. Cost O(tokens + 10*unique words).
{
    characters += length($0) + 1
    words += NF
    lines++
    count = split(tolower($0), parts, /[^a-z']+/)
    for (i = 1; i <= count; i++) {
        word = parts[i]
        sub(/^'+/, "", word)
        sub(/'+$/, "", word)
        if (word != "") frequency[word]++
    }
}
END {
    minimum = 0
    for (word in frequency) {
        unique++
        f = frequency[word]
        if (minimum == 0 || f < minimum) { minimum = f; minimum_words = 1 }
        else if (f == minimum) minimum_words++
        # Insert in descending-frequency / ascending-alphabetical order.
        if (ntop < 10 || f > frequency[top[ntop]] ||
            (f == frequency[top[ntop]] && word < top[ntop])) {
            p = ntop + 1
            if (p > 10) p = 10
            while (p > 1 && (f > frequency[top[p-1]] ||
                   (f == frequency[top[p-1]] && word < top[p-1]))) {
                top[p] = top[p-1]; p--
            }
            top[p] = word
            if (ntop < 10) ntop++
        }
        # Same insertion with frequency ascending for the least common.
        if (nbottom < 10 || f < frequency[bottom[nbottom]] ||
            (f == frequency[bottom[nbottom]] && word < bottom[nbottom])) {
            p = nbottom + 1
            if (p > 10) p = 10
            while (p > 1 && (f < frequency[bottom[p-1]] ||
                   (f == frequency[bottom[p-1]] && word < bottom[p-1]))) {
                bottom[p] = bottom[p-1]; p--
            }
            bottom[p] = word
            if (nbottom < 10) nbottom++
        }
    }
    printf "Characters: %.0f\nWords: %.0f\nLines: %.0f\nUnique words: %d\n", characters, words, lines, unique
    print "Most common words:"
    for (i = 1; i <= ntop; i++) printf "%s %d\n", top[i], frequency[top[i]]
    print "Least common words:"
    for (i = 1; i <= nbottom; i++) printf "%s %d\n", bottom[i], frequency[bottom[i]]
    printf "Lowest frequency: %d\nWords at lowest frequency: %d\n", minimum, minimum_words
    if (minimum_words > 10) {
        if (minimum == 1) printf "%d words occur only once; first 10 alphabetically shown\n", minimum_words
        else printf "%d words occur %d times; first 10 alphabetically shown\n", minimum_words, minimum
    }
}
```
